ORDER WEB

여러 프랜차이즈에 적용하는 반응형 주문 웹. 목록형·박스형 보기 전환을 구현하고, 브랜드 컬러·폰트·로고만 교체하면 되는 스킨 구조로 만들었습니다.

Order Web Web App

목표

브랜드는 달라도 주문 흐름은 같아야 하는 가맹 주문 사이트를 하나의 템플릿으로 빠르게 온보딩하는 것.

담당

기본 템플릿과 브랜드별 배포본(bhc · 육대장 · 인쌩맥주 · 탐앤탐스)의 퍼블리싱을 담당했습니다. 데스크톱과 모바일 두 화면을 함께 작업했습니다.

결과

메뉴를 목록형·박스형으로 바꿔 보는 보기 전환을 구현하고, 브랜드 컬러·폰트·로고만 교체하면 되는 스킨 구조로 마크업·스타일을 정리했습니다. 메인 · 메뉴 목록과 상세 · 장바구니 · 주문 정보 · 결제 · 주문 완료 · 로그인 · 회원가입 · 마이페이지(내 정보 · 주문내역 · 주문상세 · 쿠폰 · 즐겨찾는 메뉴), 총 17개 화면을 직접 마크업해 데스크톱과 모바일로 각각 구현했습니다.

기술

04 — 직접 마크업한 화면

디자인 시안을 받아 화면 17종을 HTML·CSS·jQuery로 직접 마크업했습니다. 데스크톱과 모바일(390px)을 각각 만들었고, 아래는 그중 대표 화면입니다.

PC · MENU

메뉴 목록 · 상세

카테고리별 메뉴 목록과, 옵션·수량을 고르는 메뉴 상세를 마크업했습니다. 목록형과 박스형으로 바꿔 보는 보기 전환도 이 화면에 들어 있습니다.

MOBILE · MENU

모바일 메뉴 화면

하단에 고정되는 주문 버튼과 옵션 선택 영역을 터치하기 편한 크기로 잡았습니다.

PC · CART

장바구니

주문 단계(장바구니 · 결제 · 주문완료)를 위쪽 스텝 바로 보여주고, 수량 조절과 삭제를 한 줄에 넣었습니다.

PC · ORDER INFO

주문 정보 입력

배송·수령 정보 입력 폼입니다. 선택한 값과 비활성 입력칸을 구분해 보이도록 스타일을 나눴습니다.

MOBILE · ORDER

주문 정보 · 결제

현금 · 카드 결제 탭, 연락처와 이메일 입력, 쿠폰 입력 영역까지 모바일 한 화면 흐름으로 이었습니다.

MOBILE · CART / FINISH

장바구니 · 주문 완료

뒤로가기와 다음 단계 버튼을 하단에 고정해 한 손으로 주문을 이어갈 수 있게 했습니다.

PC · MY ORDER

마이페이지 · 주문내역

주문 유형(배달 · 포장)을 색 라벨로 구분하고, 영수증과 상세보기 버튼을 카드마다 배치했습니다.

MOBILE · MY PAGE

마이페이지 · 쿠폰

내 정보 · 즐겨찾는 메뉴 · 주문내역 · 쿠폰으로 나뉘는 메뉴와, 쿠폰 목록 화면입니다.

MOBILE · MEMBER

로그인 · 회원가입

입력 폼 두 화면의 간격과 버튼 위치를 맞추고, 비밀번호 표시 토글과 안내 문구를 넣었습니다.
