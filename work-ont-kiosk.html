ONT KIOSK

테이블에 놓인 채로 손님이 직접 주문하는 키오스크. 1920×1080 기준으로 대기 화면부터 결제 완료까지 한 화면 안에서 흐릅니다.

Live Demo

목표

어느 기기에서나 같은 배열로 보이는, 한 가지 화면 규격에 최적화된 테이블 주문 화면. 영어와 한국어를 함께 쓰는 매장을 전제로 했습니다.

담당

화면 설계와 퍼블리싱을 담당했습니다. 라이브러리 없이 HTML · CSS · JavaScript만으로 구현했습니다.

결과

대기 화면 · 메뉴 목록 · 메뉴 상세와 옵션 · 장바구니 · 결제 · 주문 완료를 한 페이지 안에서 전환되는 구조로 구현했습니다. 1920×1080 기준 작업으로 기기가 달라도 동일한 배열의 화면을 제공합니다.
